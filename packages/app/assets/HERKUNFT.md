# Herkunft der App-Assets

- `bilder/robinienwelt_logo.png` – RobinienWelt-Logo (Eigentum der Firma), aus `web/ladebild/robinienwelt-logo.svg` mit headless Chrome gerendert (600 × 338 px, transparent).
- `schriften/Roboto-*.ttf` – Roboto Regular/Medium/Bold aus dem Flutter-SDK (`bin/cache/artifacts/material_fonts`), Lizenz Apache-2.0 (`schriften/LICENSE-Roboto.txt`). Mitgeliefert, damit der Browser keine Schriften von Google-Servern lädt (Datenschutz).
